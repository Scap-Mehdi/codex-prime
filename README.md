# codex-prime

Dépôt d'initialisation pour les projets et expérimentations Codex.

## GitHub Pages

La page web d'accueil est fournie par `index.html` à la racine du dépôt.

Pour publier le site avec GitHub Pages :

1. Ouvrir **Settings** du dépôt.
2. Aller dans **Pages**.
3. Dans **Build and deployment**, choisir **Deploy from a branch**.
4. Sélectionner la branche `main` et le dossier `/ (root)`.
5. Enregistrer.

Le site sera ensuite servi depuis l'URL GitHub Pages associée au dépôt.
