À propos du projet

Codex Prime

Codex Prime est un dépôt d’initiation destiné à expérimenter le développement web, versionner du code avec GitHub et publier des pages avec GitHub Pages.

Ce site constitue un point de départ simple : des pages HTML accessibles, adaptables et sans dépendance externe.

Le projet est amené à évoluer au fil des exercices et des contributions.

Projet hébergé sur GitHub.
